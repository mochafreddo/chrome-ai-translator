# GitHub 릴리스 Partial Translation 설계 인터뷰

이 문서는 2026-10-30의 [mattpocock/skills v1.3.2 릴리스](https://github.com/mattpocock/skills/releases/tag/v1.3.2) Inline Translation 조사와 설계 인터뷰를 기록한다. 조사 기준은 `cc1ad3be34beea2df2fb5b50a5a34b877b8b92de`이다. 사용자는 Q1부터 Q4까지의 추천안과 Q5의 최종 설계를 모두 수락했다. 후속 `implement` 요청으로 구현과 새 워크트리의 커밋을 승인했다.

## 관측과 한계

사용자가 제공한 schema-3 진단에는 초기 검증과 보정 검증 모두 `quality.english_residue`인 블록 하나가 있다. 해당 블록은 구조 검사를 통과했으며 모델 요청 2회, 보정 1회 후 `apply_with_warning`으로 적용됐다. 최종 품질 근거는 원문 302자, 원문 prose 37단어, 출력 225자, 출력 문자 중 Unicode letter 118개와 한글 음절 81개, 원문과 겹치는 영어 3단어 연속 구간 1개다. 진단에 기록된 모델은 `gpt-6-luna`, 대상 언어는 `ko`다.

진단에는 원문과 번역문, 일치한 영어 문구, 초기 응답의 품질 수치, 실제 보정 요청의 문맥 포함 여부가 없다. 따라서 일반 설명문의 미번역인지 기술 이름의 오탐인지, 보정이 얼마나 개선했는지, 현재 소스가 당시 실행된 확장과 같은지는 아직 확정할 수 없다. 별도의 `runtime.unsupported_block` 기록은 모델 호출 전의 거부이며 이 Partial Translation과 구분한다.

현재 구현은 구조가 안전한 첫 응답에 영어 잔류가 있으면 보정을 요청하며, 용량 제한에 맞을 때만 이전 답변과 일치 문구를 보정 문맥에 포함한다. 보정 후에도 영어 잔류 판정이 남으면 Partial Translation으로 적용한다. 책임과 진단의 개인정보 경계는 [architecture](../architecture.md#inline-translation)와 [ADR-0009](../adr/0009-model-local-rejections-in-diagnostics-v3.md)에 있다. 이 소스 확인은 보고된 문구 자체의 오탐 여부를 증명하지 않는다.

## 무료 재현 관측

별도의 임시 agent-browser 세션에서 공개 페이지를 읽고 현재 codec으로 직렬화한 블록은 27개다. 원문 302자와 prose 37단어를 모두 만족한 후보는 `wayfinder` 변경 사항 문단 하나다. 그 문단에는 코드 atom과 여러 기여자 계정 링크가 있다. 계정 링크는 현재 보호된 atom이 아니라 번역할 수 있는 wrapper로 직렬화된다.

이 문단의 일반 설명문을 한국어로 바꾸고 식별자와 계정 이름을 보존한 고정 응답을 현재 `execute` 공개 접점으로 두 번 반환했다. 실제 모델 호출 없이 구조 safe, `quality.english_residue`, 영어 연속 구간 길이 3·개수 1, `apply_with_warning`을 재현했다. 이는 적절히 보존된 계정 이름을 미번역으로 판정할 수 있다는 근거다. 사용자 실행의 실제 번역문은 없으므로 그 실행의 정확한 원인까지 확정하지는 않는다. 고정 응답의 출력 길이는 사용자 진단과 다르다.

실험의 첫 시도는 바깥 LI를 선택한 상태에서 직렬화 결과를 확인하지 않아 실패했다. 두 번째 시도에서 화면에 보이게 한 뒤에도 `empty_content / LI`가 확인됐다. 후보 DOM을 조회해 자체 본문이 있는 P와 바깥 LI를 구분한 뒤 P를 사용한 실험이 통과했다. 세 시도는 모두 실제 모델을 호출하지 않았다.

## 합의한 방향

### Q1: 실제 번역 품질과 판정 정확성

사용자는 추천안을 수락했다. 일반 설명문은 한국어로 번역하고 실제 코드·경로·식별자는 보존한다. 문제 구간을 확인한 뒤 미번역이면 번역 처리를, 오탐이면 판정기를 수정하는 방향으로 원인을 좁힌다. 경고 개수만 줄이는 것을 성공 기준으로 삼지 않는다.

### Q2: 보정 횟수

사용자는 추천안을 수락했다. 자동 보정은 블록당 최대 1회를 유지한다. 보정 횟수를 늘리기 전에 요청과 판정의 문제를 확인한다.

### Q3: 보정 후 Partial Translation 적용

사용자는 추천안을 수락했다. 보정 후에도 미번역이 남으면 구조가 안전한 번역 결과를 적용하고 Partial Translation을 표시한다. 구조가 안전하지 않은 결과는 적용하지 않는다.

### Q4: 계정 링크 식별자 보호

사용자는 추천안을 수락했다. 링크 문구 전체가 `@계정명`이면 기존 보호된 링크와 같이 이름을 보존하고 번역 품질 검사에서 제외한다. 주변 감사·설명 문장은 계속 번역한다. 일반 링크 제목이나 사람의 표시 이름까지 제외하지 않는다.

## 확정한 설계

사용자는 Q5에서 다음 작업 범위, 공개 테스트 접점, 검토 기준과 검증 범위를 확정했다. 이 설계 확인은 구현 요청이나 유료 호출 승인을 대신하지 않는다.

- 저장소는 `/Users/jw.kim/workspaces/chrome-ai-translator`이며 검토 기준은 조사 기준인 `cc1ad3be34beea2df2fb5b50a5a34b877b8b92de`로 유지한다. 인터뷰 중 HEAD가 `6a2f6088184dcb40a6fffe20f86572de83d2c099`로 바뀌었으나 추가 커밋은 이슈 절차 문서만 변경했다. 두 기준 사이의 codec과 모델 실행 소스는 동일하다. 다른 세션의 변경은 이 작업에 포함하지 않는다.
- 수정 대상은 Inline Translation의 계정 링크 분류다. 문구 전체가 공백 없는 `@계정명` 형식인 링크를 기존 보호된 링크 atom 경로에 넣는다. 사이트 주소별 예외, 일반 표시 이름·링크 제목의 일괄 제외, 링크가 아닌 평문 계정 표기의 새 지원은 범위에 넣지 않는다. 기존 계정 식별자 이외의 보호 규칙은 유지한다.
- 보존 계약은 계정 이름, 링크 대상과 DOM 객체를 유지하면서 주변 설명문을 번역하는 것이다. 기존 atom의 어순 이동, 적용과 원문 복원 경로를 재사용한다. 자동 보정은 최대 1회이고, 보정 후 실제 영어 잔류가 있으면 안전한 결과를 Partial Translation으로 적용한다.
- 공개 단위 검사 접점은 codec의 `serializeBlock`, `validateTranslatedTemplate`, `applyTranslatedTemplate`, `restoreBlock`과 모델 실행의 `execute`다. 계정 링크 보존, 일반 링크 제목의 번역 가능성, 계정만 남은 완전 번역의 오탐 방지와 실제 설명문 미번역의 검출을 확인한다. 오탐 회귀 검사는 미수정 코드에서 실패하는 음성 대조를 포함한다.
- 무료 브라우저 검증은 기여자 목록을 포함한 로컬 fixture와 보고된 공개 릴리스 페이지를 분리한다. 고정 한국어 응답으로 이름·링크·DOM 객체 보존, 실제 영어 설명문 검출, 적용과 정확한 원문 복원을 검사한다. 공개 페이지 결과는 검사 당시의 관측이며 과거 사용자 실행이나 실제 모델 품질을 증명하지 않는다.
- 구현 후 로컬 검증은 기존 `npm run verify:local` 절차의 lint·구문·문서·단위 검사와 관련 무료 브라우저 검사로 구성한다. 실제 모델 호출, 키 접근, 영구 진단에 원문·번역문 추가, 커밋·원격 게시와 배포는 포함하지 않는다. 실제 모델 품질 확인이 필요해지면 별도 범위와 비용을 결정한다.

## 후속 구현 요청

사용자는 설계 확정 후 `implement` 스킬과 새 워크트리를 요청했다. 원격을 새로 조회한 시점의 `origin/main`과 로컬 `main`은 모두 `6a2f6088184dcb40a6fffe20f86572de83d2c099`이며, 이를 새 워크트리의 시작점으로 사용했다. 조사 기준 이후의 추가 커밋은 이슈 절차 문서만 변경했다. 원래 체크아웃의 설계 문서 변경은 남겨 두고 승인된 설계 기록을 구현 워크트리에 복사했다. 작업의 검토 기준은 위에서 확정한 조사 기준으로 유지한다.

제품 수정은 기존 보호 링크 판별 함수에서 영문자·숫자·밑줄로 시작하고 이후 영문자·숫자·밑줄·하이픈으로 구성된 `@계정명`을 식별하는 규칙이다. 링크가 아닌 평문은 이 규칙을 거치지 않는다. 새 용어나 ADR은 추가하지 않았으며, 기존 atom과 번역 품질 검사 경로를 재사용한다.

단위 회귀 검사는 수정 전 `apply_with_warning`으로 실패했고 수정 후 통과했다. 최종 형태의 회귀 검사도 수정 한 줄을 제거한 임시 복사본에서 같은 종류의 실패를 검출했다. 로컬 fixture와 공개 릴리스 문단의 무료 브라우저 검사는 고정 한국어 응답으로 완전 번역 판정, 계정 이름·링크·노드 보존, 정확한 원문 복원과 실제 영어 잔류 경고를 확인했다. 공개 페이지 결과는 당시 관측이며 실제 모델 품질이나 과거 실행의 정확한 원인을 확정하지 않는다. 실행 명령과 범위는 [테스트 가이드](../../tests/README.md#unbilled-chrome-checks)에 있다.

실제 모델 호출, 자격 증명 접근, 원격 게시와 배포는 이 구현 요청에 포함하지 않는다.

새 도메인 용어는 추가하지 않는다. 기존 [glossary](../../GLOSSARY.md)의 Partial Translation과 Source Syntax 정의를 적용한다. 새로운 구조적 대안을 선택하지 않았으므로 ADR은 추가하지 않는다.
