# Arena 호출 문구와 단계 참조 설계 인터뷰

2026-11-27 [Arena 문서](https://github.com/cursor/plugins/blob/b7b93c36be9bcc36a74db438e0fd385d660bc559/pstack/skills/arena/SKILL.md)의 한국어 Inline Translation 보고를 조사하고 Q1–Q5의 설계를 확정했다. 검토 기준은 `63331cf28150b55cc437337ae2595ed8c1ad6c17`이다. 최종 범위 제안 전에 로컬 `HEAD`와 원격 `main`이 이 커밋과 일치함을 확인했다.

## 보고된 경고

첨부 진단은 세 Semantic Block 모두에서 최초 응답의 `quality.english_residue`에 이어 보정 응답의 `apply_with_warning`을 기록했다. 화면에 적용된 번역문을 당시 조사 기준의 판정기에 재입력했을 때 각 블록의 수치가 진단과 일치했다. 원문 링크는 로컬 재현에 사용한 GitHub HTML의 브랜치 커밋을 가리킨다. 당시 브라우저의 정확한 원문 리비전과 최초 모델 응답 본문은 확인할 수 없었다.

- `description`에는 `arena this`와 `throw it in the arena`가 한국어 뜻과 함께 남았다. 긴 호출 문구의 겹치는 네 단어 구간 두 개가 진단에 기록됐다. 두 문구를 제거하고 `/arena`를 유지한 결과는 검사를 통과했다.
- Phase E 마지막 문단과 Phase F 본문에서는 `Phase A`가 일치했다. `A`가 소문자화되어 영어 관사 표지에 걸렸다. Phase F 본문에서 `Phase A`만 한국어로 옮기고 `Phase E`를 남겨도 기존 검사는 통과했다.

## 합의한 동작

- **Q1. 호출 문구.** 저자가 기능 호출에 쓰도록 직접 제시한 자연어 표현은 영어 원문과 인접한 한국어 뜻을 제공한다. 확인된 위치의 원문 보존은 Partial Translation 판정에서 제외한다. 일반 인용문과 설명은 한국어로 번역한다. [Invocation Phrase와 Language Example의 정의](../../GLOSSARY.md)를 따른다.
- **Q2. 단계 참조.** 문서 자체의 단계를 가리키는 `Phase A`, `Phase E`는 제목과 본문에서 `A 단계`, `E 단계`처럼 글자를 유지해 번역한다. 독자가 도구에 `Phase A`를 그대로 입력하도록 원문이 제시하는 문맥에는 Q1을 적용한다.
- **Q3. 응답 계약.** 한국어 응답의 `languageExamples`를 `preservedExpressions`로 바꾸어 Language Example과 Invocation Phrase를 한 배열에 담는다. 모델은 두 유형의 의미를 구분한다. 코드는 같은 응답에서 기존의 원문 일치, UTF-16 위치, 인접한 한국어 뜻, 중복·중첩 및 구조 보호 검사를 재사용한다. 검증된 출력 위치만 잔류 검사에서 제외하며 보정 응답도 원문을 기준으로 새 위치를 검증한다. 메타데이터는 응답 검증 중에만 사용한다. 위치 검사가 보장하는 범위는 실제 문자열과 응답의 일치까지다.
- **Q4. 단계명 잔류.** 한국어 Inline Translation에서 원문의 `Phase`와 단독 대문자 한 글자 조합이 출력에도 남으면 기존 두 단어 비교 대상으로 다룬다. 검증된 원문 보존 위치와 기존 보호 구간을 제외한 뒤 비교하며, 최장 일치 우선순위와 최대 한 번 보정을 유지한다. 일반 텍스트에 보호되지 않은 공식 이름이 같은 철자로 쓰이면 그 이름에도 보정과 경고가 발생할 수 있다.

## 확정한 작업 및 검증 범위

- 한국어 대상 Inline Translation의 번역 지시, 제공자 응답 스키마와 판독, 위치 검증과 잔류 판정, 모델 품질 평가 도구의 스키마 검사와 모의 응답, 관련 문서를 갱신한다. 기존 번역 요청에서 분류를 함께 수행하며, 구조 보호, Source Syntax와 Session의 적용·복원 계약을 유지한다.
- 검토에는 이 설계 기록과 용어집 변경을 포함한다. 모델 실행의 `execute`와 `assessTranslationQuality`, 워커에서 Session과 DOM 적용·복원으로 이어지는 기존 모의 요청 흐름을 공개 테스트 접점으로 쓴다.
- 호출 문구와 한국어 뜻의 적용·복원, 일반 산문과 인용문 잔류, 뜻 누락과 잘못된 위치, 보호 구간, 기존 Language Example, 다른 대상 언어를 확인한다. 초기 응답 스키마와 보정 요청을 검사한다. `Phase A`를 한국어로 옮겼어도 `Phase E`가 남으면 보정하고, 이 참조가 보정되면 완료, 그대로 남으면 Partial Translation이 되는 사례를 둔다.
- 회귀 검사가 수정 전 동작에서 실패하는지 확인한 뒤 수정 후 `npm run verify:local`로 lint·구문·문서·단위 검사를 실행한다. 고정 응답과 로컬 DOM fixture의 검증 범위는 요청·응답 계약과 결과 처리다. 실제 모델의 분류·번역 품질과 실제 브라우저 검증은 별도 범위다.

각 라운드의 권고안은 작성자와 다른 `gpt-6.2-astra` Codex `reviewer`로 독립 검토했다. 본 기록은 설계 합의를 남긴다. 제품 구현과 명세 게시에는 별도 요청이 필요하다.
