A page held still

This page exists so the live check has something fixed to translate. A page on the open web would do the job until its owner edited a sentence, and then the check would change what it costs and what it asserts without anyone having touched it.

Three short blocks is all this page shows at first, on purpose. The check bills a real model, so the fixture is what decides the size of the bill, and keeping that decision here means it is visible to whoever changes it.

This paragraph stays out of the first run so that the run after it has something the translation cache has never seen. A run served entirely from that cache issues no request, and stopping it would prove nothing.
