# 언어 예문과 Partial Translation 설계 인터뷰

이 문서는 2026-11-11의 [cursor/plugins unslop 문서](https://github.com/cursor/plugins/blob/main/pstack/skills/unslop/SKILL.md) Inline Translation 보고와 설계 인터뷰를 기록한다. 소스 조사 기준은 `6e0a9fd681dab2cb2b9667c8937409afe0b824b9`이다. 사용자는 Q1부터 Q4까지의 추천안을 수락해 설계를 확정했다. 제품 구현은 시작하지 않았다.

## 관측과 한계

사용자가 제공한 schema-3 진단의 `run-1794405009759-9bggtv/b1-41`은 최초 검증과 보정 검증 모두 `quality.english_residue`이며, 구조 검사를 통과한 결과를 `apply_with_warning`으로 적용했다. 기록된 모델은 `gpt-6-luna`, 대상 언어는 `ko`다. 해당 실행은 블록 하나, 모델 요청 두 번, 보정 한 번이며 실패 블록은 없다. 원문 303자·prose 49단어, 출력 215자·Unicode letter 154개·한글 음절 97개, 겹친 영어 연속 구간 길이 4·개수 4가 기록됐다.

조사 당시 공개 원문의 29번 능동태 설명 항목은 번호와 Markdown 강조 표시를 제거하면 301자이며 영어 단어가 49개다. 이는 후보를 좁히는 근거일 뿐, 브라우저에서 직렬화한 블록과의 일치 증명이 아니다. 원문에는 영어 수동태와 능동태를 비교하는 예문이 있다. 실제 사용자 번역문과 일치한 영어 문구는 진단에 없으므로, 이 항목이 문제 블록인지와 언어 예문 보존이 실제 경고 원인인지는 확정하지 않았다. 현재 소스와 당시 실행된 확장의 동일성도 확인하지 않았다.

현재 품질 판정은 원문과 출력에 겹친 영어 연속 구간을 검사한다. 구조가 안전한 응답에서 영어 잔류가 확인되면 최대 한 번 보정하며, 이후에도 잔류가 남으면 경고와 함께 적용한다. 현재 번역 지시는 인용 부호만으로 원문을 보존하지 않도록 요구하며 Language Example을 별도로 다루지 않는다. 현재 책임은 [architecture](../architecture.md#inline-translation), 용어는 [glossary](../../GLOSSARY.md)에 있다.

## 합의한 방향

### Q1: 영어 표현 자체를 설명하는 예문

사용자는 추천안을 수락했다. 일반 설명은 한국어로 번역하고, 영어 표현 자체가 설명 대상인 예문은 영어 원문과 한국어 뜻을 함께 제공한다. 따옴표가 있다는 이유만으로 모든 인용문을 보존하지 않는다. 이 개념은 Language Example으로 정의한다. 원문과 뜻이 함께 제공된 Language Example의 영어 보존 자체는 Partial Translation의 근거가 되지 않는다.

이 원칙은 제품의 목표 동작이며 현재 구현 완료를 뜻하지 않는다. 식별 및 검증 방식은 Q3에 기록한다. 실제 미번역 설명문 검출을 유지하며 경고 개수만 줄이는 것을 성공 기준으로 삼지 않는다.

### Q2: 예문 인정 범위

사용자는 추천안을 수락했다. 영어 표현의 문법·어휘·문체 자체를 설명하고 한국어 뜻도 제공한 경우에만 Language Example의 원문 보존을 인정한다. 일반 인용문이나 제목, 한국어 뜻 없이 남은 영어는 계속 미번역 검사 대상으로 둔다. 예문인지 불분명한 구간을 일괄 제외하지 않는다.

### Q3: 예문 식별과 기계적 검증

사용자는 추천안을 수락했다. 기존 번역 요청의 응답에 예문 원문·한국어 뜻·출력 위치 정보를 함께 받는다. 모델이 문맥상 예문인지 판단하고, 코드는 원문 일치와 출력 내 원문·뜻의 병기 및 위치를 검증한다. 검증된 해당 위치만 잔류 검사에서 제외하고, 불일치·누락·모호한 위치는 제외하지 않는다. 별도 예문 분류 요청은 추가하지 않는다.

기계적 검증은 예문 분류나 번역 의미의 정확성까지 보장하지 않는다. 의미 판단은 모델의 책임이며, 코드 검사는 응답 근거와 실제 입력·출력의 일치 여부를 보장하는 경계다. 같은 영어 표현이 출력의 다른 위치에 남아 있으면 해당 위치는 별도로 검사한다. 검증 범위가 Placeholder Token이나 Source Syntax를 훼손할 수는 없다.

## 확정한 설계

사용자는 Q4에서 다음 작업 범위, 공개 테스트 접점, 검토 기준과 검증 범위를 모두 확정했다. 이 설계 확인은 구현 요청이나 유료 호출 승인을 대신하지 않는다.

- 저장소는 `/Users/mochafreddo/GitHub/chrome-ai-translator`이고 검토 기준은 `6e0a9fd681dab2cb2b9667c8937409afe0b824b9`이다. 이 인터뷰에서 작성한 용어집·설계 기록·문서 색인 변경도 검토 대상에 포함한다. 구현 시작 시 다른 세션의 변경과 원격 상태를 확인하고 보존한다.
- 제품 변경 범위는 Inline Translation의 영어 원문에서 한국어로 번역하는 경로다. 번역 지시, 응답 형식, 예문 메타데이터 검증과 잔류 판정을 함께 변경한다. 특정 사이트 주소 예외나 모든 인용문의 일괄 제외는 추가하지 않는다. 다른 대상 언어의 기존 판정과 다른 번역 경험은 유지한다.
- 예문 메타데이터는 해당 응답의 검증에만 사용한다. 원문·번역문·뜻·위치 정보를 영구 진단이나 진단 내보내기에 추가하지 않는다. 기존 구조 보호, 최대 한 번 보정, 안전한 부분 번역의 경고 적용과 위험한 결과의 거부를 유지한다.
- 공개 테스트 접점은 모델 실행의 `execute`와 `assessTranslationQuality`, 기존 worker 요청 흐름, codec의 `serializeBlock`·`applyTranslatedTemplate`·`restoreBlock`이다. 보고된 문서의 능동태 항목을 바탕으로 만든 고정 입력·응답을 사용하며, 사용자 실제 응답의 재현으로 표현하지 않는다.
- 검사 사례는 예문과 한국어 뜻이 함께 있는 정상 결과, 일반 인용문·제목·설명문의 영어 잔류, 뜻 누락, 잘못된 위치·원문 불일치·중복 표현·겹치는 범위, Placeholder Token 및 Source Syntax 보존, 첫 응답과 보정 응답, DOM 적용·복원과 캐시 재사용이다. 예문 오탐 회귀 검사는 미수정 코드에서 실패하는 음성 대조를 포함한다.
- 최종 로컬 검증은 `npm run verify:local`로 lint·구문·문서·단위 검사를 실행한다. 고정 응답과 로컬 DOM fixture의 결과는 무료 결정론적 검증으로 구분한다. 실제 브라우저·실제 모델 품질과 과거 사용자 실행 원인은 이 검증만으로 확인되지 않는다.
- 유료 모델 호출, 자격 증명 접근, 설치, 커밋·푸시·병합·배포는 이번 설계 확인에 포함하지 않는다. 구현은 별도 요청 후 진행한다.

## 수행 범위

첨부 진단, 공개 원문, 현재 소스와 기존 설계 기록을 읽었다. 독립된 읽기 전용 조사로 모델 실행부터 Session의 적용·메시지 생성까지 경로를 확인했다. 공개 원문 수집은 네트워크 제한으로 한 번 실패한 뒤 허용된 네트워크 실행으로 성공했다. 실제 모델 호출, 사용자 브라우저 관측, 회귀 재현과 제품 테스트는 수행하지 않았다. 따라서 과거 실행의 원인 확정이나 수정 완료를 주장하지 않는다.

## 명세 게시

이슈는 `ready-for-agent` 라벨이 붙은 열린 상태이며, 게시 도구의 원격 재조회로 제목·본문·요청 라벨과 상태를 확인했다. 공개 테스트 접점은 Q4의 합의를 그대로 사용했다. 게시 완료는 제품 구현이나 수락 기준 충족을 뜻하지 않으며, 제품 구현은 시작하지 않았다.
